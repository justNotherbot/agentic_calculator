# Scenario Screenshots

Run `npm run test:client` to refresh these desktop screenshots of the working page:

- `empty.png`: initial empty history, with a mocked empty `GET /api/history` response.
- `loading.png`: pending calculation, with the `POST /api/history` response held by the test.
- `success.png`: result returned by the real Node API and visible in history.
- `error.png`: failed save with the input retained and retry available, with a mocked server error.

The screenshots are generated by the `captures the main scenario states` Playwright test. The test asserts the state before taking each screenshot. See `client-tests/calculator.spec.js` for the exact request setup and assertions.
